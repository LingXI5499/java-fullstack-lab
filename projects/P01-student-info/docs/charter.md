# P01 学生信息管理系统 —— 项目章程

> **用途**：本项目的第一份文档。G1 规格闸门的第一项判据就是"章程齐备"。
> **填写时机**：S0 工序 01，在任何需求卡之前。
> **产出位置**：`projects/P01-student-info/docs/charter.md`（本文件）

## 1. 一句话定位

用最小、最干净的一套代码，把"**Vue → Axios → Controller → Service → Mapper → MyBatis XML → MySQL**"
这条主干链路打通到可以脱口而出的程度，同时把流水线的骨架、门禁与技能库验证一遍。

## 2. 为什么是第一个项目

P01 的价值不在业务，而在于**它是整条流水线的首次运行**：

- 它验证 `jfsl-scaffold` 生成的骨架是否真的可编译、可启动；
- 它验证单库 + `p0N_` 前缀隔离是否可行；
- 它验证 `jfsl-crud-gen` 生成八件套后，用户能顺利补完业务规则；
- 它产出第一批真实的返工数据，供 `docs/pipeline/metrics.md` 建表。

**因此 P01 的验收标准比后九个项目更严**：链路必须完整，不许为了快而跳过任何一层。

## 3. 训练目标

### 3.1 本项目新增的技术点（只允许 1–2 个）

1. **统一返回与全局异常**：`Result<T>` + 业务异常继承体系 + `@RestControllerAdvice`
2. **条件 + 分页查询的动态 SQL**：MyBatis `<if>` / `<where>` / `<trim>` + `LIMIT`

> 除这两个之外，本项目不得引入任何新技术。JWT、文件上传、事务编排等留给后续项目。

### 3.2 完成后应达到的能力等级（母版 L0–L5）

| 能力 | 目标等级 | 判定方式 |
|---|---|---|
| 主干请求链路 | L4 | 能不看代码画出新增学生的完整调用链，并指出每层职责 |
| MyBatis 动态 SQL | L3 | 能独立写出多条件分页查询的 XML |
| 统一返回与异常 | L3 | 新增一个错误时，能自己加异常子类与错误码 |
| Vue 后台列表页 | L3 | 能独立完成"搜索 + 表格 + 分页 + 弹窗表单" |
| 部署与排错 | L3 | 能按 Runbook 在陌生机器上把它跑起来 |

## 4. 范围

### 4.1 做

- 专业（major）、班级（class）、学生（student）三个实体的完整 CRUD
- 学生的条件查询（姓名模糊 / 学号精确 / 班级 / 状态）与分页
- 前端：登录占位页（不做真实认证）、学生列表页、学生表单弹窗、基础统计卡片
- 后端：统一返回、参数校验、业务异常、日志、Swagger
- 交付：schema + seed、JUnit + MockMvc、冒烟脚本、Nginx + systemd 配置、Runbook、tag

### 4.2 不做

| 不做 | 留给谁 |
|---|---|
| 真实登录认证（JWT） | P06 博客系统 |
| 角色与权限控制 | P06 / P07 |
| 文件上传 | P06 |
| 事务编排（涉及多表写入） | P02 图书借阅 |
| 乐观锁与并发处理 | P04 仓库管理 |
| 任何 Redis / MQ / 微服务 | 流水线下一版 |
| 花哨的前端动效 | 不做，界面只要"整齐可用" |

## 5. 约束

| 类型 | 约束 |
|---|---|
| 时间 | 3 个工作日（含门禁与复盘）；超出即在复盘里分析原因 |
| 环境 | JDK 17 编译目标、MySQL 8（库 `java_fullstack_lab`）、Node 20+、pnpm |
| 技术 | 严格遵守 [AGENTS.md](../../../AGENTS.md)：MyBatis 手写 XML、禁止 `record`、`star-rain` 包结构 |
| 数据库 | 只使用 `p01_` 前缀的表；禁止跨项目 JOIN 与外键 |
| 端口 | 后端 8101，前端 5174 |
| 秘密 | 数据库密码只写在 `application-local.yml`（已 gitignore） |
| 人工智能边界 | AI 搭骨架、写契约、写测试骨架；业务规则、SQL、页面交互、业务断言由用户实现 |

## 7. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 骨架模板首次生成，必然有缺陷 | 阻塞 S2 | 缺陷本身就是 P01 的主要产出；每条都记进 `discovery-record.md` 并回写 `jfsl-scaffold` |
| 本机 JDK 21 编译出 21 的字节码 | 与基线不符，CI 可能失败 | 门禁检查 `javap` 的 major version 为 61 |
| 单库前缀隔离被无意破坏 | 污染其他项目 | 门禁扫描 `database/**` 与本项目 SQL 中的表名前缀 |
| 前端工程体积首次搭建 | 拖慢后续项目 | P01 就把 pnpm workspace 与共享 `node_modules` 建好 |
| 需求范围蔓延 | 拖期 | 任何新增走 `change-impact.md`，本项目的"不做"清单是硬边界 |
